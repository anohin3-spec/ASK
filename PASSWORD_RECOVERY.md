# 🔑 Восстановление забытого пароля

## Для обычных пользователей

Если вы **не администратор** и забыли пароль:

1. Обратитесь к **администратору** вашей организации
2. Администратор сбросит ваш пароль через программу
3. Вы получите **временный пароль**
4. При первом входе смените пароль на постоянный через меню "Файл" → "Сменить пароль"

---

## Для администраторов

Если вы **администратор** и забыли пароль:

### Способ 1: Экстренный скрипт (рекомендуется)

1. **Откройте PowerShell** в папке программы
2. **Запустите скрипт:**
   ```powershell
   python reset_admin_password.py
   ```
3. **Следуйте инструкциям:**
   - Введите ваш username (по умолчанию: `admin`)
   - Введите новый пароль (минимум 6 символов)
   - Подтвердите новый пароль
   - Подтвердите действие (`да`)

4. **Войдите с новым паролем**

### Пример использования:

```powershell
PS C:\Users\anohi\Desktop\ASK> python reset_admin_password.py

============================================================

============================================================

Введите username пользователя: admin

📋 Найден пользователь:
   Username: admin
   Полное имя: Администратор
   Роль: admin

Введите новый пароль (минимум 6 символов): ******
Подтвердите новый пароль: ******

⚠️  Вы уверены, что хотите сбросить пароль? (да/нет): да

⚠️  ВАЖНО: Запишите новый пароль в безопасном месте!
```

## Сброс пароля других пользователей (для администраторов)

В программе (после входа как администратор):

1. Откройте вкладку **"Пользователи"** (будет добавлена в Этапе 3)
2. Выберите пользователя
3. Нажмите кнопку **"Сбросить пароль"**
4. Введите временный пароль
5. Сообщите пользователю новый пароль
6. Пользователь должен сменить пароль при первом входе

---

## Требования

- Программа должна быть в режиме **cloud** (`MODE=cloud` в файле `.env`)
- Должно быть подключение к интернету
- Учетные данные Supabase должны быть указаны в `.env`

---

## Безопасность

⚠️ **ВАЖНО:**
- Скрипт `reset_admin_password.py` - это инструмент экстренного восстановления
- Используйте только когда нет другого способа войти в систему
- После сброса **обязательно смените пароль** на безопасный
- Не используйте простые пароли (123456, password, admin и т.д.)
- Храните пароли в надежном месте (менеджер паролей)

---

## Что делать, если скрипт не работает?

### Ошибка: "Не установлены необходимые библиотеки"
```powershell
pip install supabase bcrypt
```

### Ошибка: "Скрипт работает только в режиме cloud"
Откройте файл `.env` и убедитесь, что там указано:
```
MODE=cloud
```

### Ошибка: "Не найдены учетные данные Supabase"
Проверьте файл `.env`, должны быть указаны:
```
SUPABASE_URL=ваш_url
SUPABASE_KEY=ваш_ключ
```

### Ошибка: "Пользователь не найден"
Убедитесь, что вы правильно ввели username (с учетом регистра)

---

## Примечания

- Пароль **не отображается** при вводе (это нормально, для безопасности)
- Минимальная длина пароля: **6 символов**
- Пароль может содержать буквы, цифры и спецсимволы
- Рекомендуется использовать **сложные пароли** (комбинация букв, цифр, символов)

---

## Контакты

Если возникли проблемы:
1. Проверьте подключение к интернету
2. Убедитесь, что Supabase база данных доступна
3. Проверьте правильность учетных данных в `.env`
