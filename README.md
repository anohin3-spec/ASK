# Система учета технического обслуживания техники

Программа для отслеживания ТО техники, управления водителями и регистрации неисправностей.

## Возможности

### Управление техникой
- Добавление/редактирование техники
- Учет по пробегу или моточасам
- Автоматический расчет следующего ТО
- Разные интервалы для летнего и зимнего периода
- Привязка водителей к технике (1-2 водителя на единицу)
- Отслеживание страховки и сервиса

### Регистрация ТО
- Внесение данных о прохождении ТО
- Указание пробега/моточасов
- Добавление комментария
- Прикрепление файла со счётом
- История всех ТО

### Регистрация неисправностей
- Добавление неисправностей между ТО
- Привязка к водителю, сообщившему о проблеме
- Отслеживание статуса (открыта/закрыта)
- Комментарий к решению

### Управление водителями
- Добавление водителей с именем и телефоном
- Привязка к технике
- Просмотр закрепленной техники

### Отчеты и экспорт
- Общая статистика
- Экспорт всех данных в Excel
- Выборочный экспорт (техника, ТО, неисправности)
- Цветовое выделение по статусу

## Установка

### Требования
- Python 3.8 или выше
- Windows (программа использует tkinter)

### Шаги установки

1. Убедитесь, что Python установлен:
```bash
python --version
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

## Запуск программы

```bash
python main.py
```

## Использование

### Добавление техники
1. Откройте вкладку "Техника"
2. Нажмите кнопку "➕ Добавить"
3. Заполните данные:
   - Название техники
   - СТС/ПТС
   - Регистрационный номер
   - Тип учета (пробег или моточасы)
   - Текущее значение пробега/моточасов
   - Интервалы ТО для лета и зимы
4. Нажмите "Сохранить"

### Добавление водителя
1. Откройте вкладку "Водители"
2. Нажмите "➕ Добавить"
3. Введите имя и телефон
4. Нажмите "Сохранить"

### Привязка водителей к технике
1. На вкладке "Техника" выберите технику
2. Нажмите кнопку "👥 Водители"
3. Выберите водителей из списка (можно выбрать несколько)
4. Нажмите "Сохранить"

### Регистрация ТО
1. Выберите технику на вкладке "Техника"
2. Нажмите "🔧 Регистрация ТО"
3. Заполните данные:
   - Пробег/моточасы при ТО (автоматически заполняется текущим значением)
   - Дата ТО
   - Комментарий
   - Прикрепите файл счёта (если есть)
4. Нажмите "Сохранить"

### Регистрация неисправности
1. Выберите технику на вкладке "Техника"
2. Нажмите "⚠️ Неисправность"
3. Выберите водителя (опционально)
4. Введите описание неисправности
5. Нажмите "Сохранить"

### Закрытие неисправности
1. Откройте вкладку "Неисправности"
2. Выберите открытую неисправность
3. Нажмите "✅ Закрыть"
4. Введите комментарий к решению
5. Нажмите "Закрыть неисправность"

### Экспорт в Excel
1. Выберите "Файл" → "Экспорт в Excel" в меню
   ИЛИ
2. Перейдите на вкладку "Отчеты и статистика"
3. Выберите нужный вариант экспорта:
   - Экспорт всех данных
   - Экспорт списка техники
   - Экспорт истории ТО
   - Экспорт неисправностей

## Особенности

### Автоматический расчет ТО
- Программа автоматически определяет текущий сезон
- Зимой (октябрь-март): используется зимний интервал ТО
- Летом (апрель-сентябрь): используется летний интервал ТО
- Цветовая индикация:
  - 🟢 Зеленый: ТО не требуется
  - 🟡 Желтый: Скоро ТО (осталось менее 20% интервала)
  - 🔴 Красный: Требуется ТО!

### Хранение данных
- Все данные хранятся в локальной базе SQLite
- База данных: `maintenance.db`
- Счета сохраняются в папке `invoices/`
- Для онлайн-доступа в будущем база данных может быть перенесена на сервер

### Настройки
- Меню "Файл" → "Настройки"
- Указание корневой папки для хранения файлов
- Интервалы ТО по умолчанию

## Резервное копирование

Для сохранности данных рекомендуется регулярно копировать:
- Файл `maintenance.db`
- Папку `invoices/`
