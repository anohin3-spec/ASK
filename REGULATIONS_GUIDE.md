# Управление регламентами технического обслуживания

## Описание функции

Система управления регламентами ТО позволяет хранить и быстро открывать файлы регламентов для разных типов техники.

## Поддерживаемые типы техники

- **Case 570** - экскаватор-погрузчик
- **Hidromek** - экскаватор
- **Камаз** - грузовой автомобиль
- **FAW** - грузовой автомобиль

## Как использовать

### Доступ к регламентам

1. Перейдите на вкладку **"История ТО"**
2. Нажмите кнопку **"Регламенты"** на панели инструментов
3. Откроется окно управления регламентами

### Добавление регламента

1. В окне регламентов выберите тип техники из списка
2. Нажмите кнопку **"Добавить файл"**
3. Выберите файл регламента на вашем компьютере
   - Поддерживаются форматы: PDF, Word (doc/docx), Excel (xls/xlsx), изображения (png/jpg/jpeg)
4. Файл будет скопирован в папку программы

### Открытие регламента

**Способ 1:** Двойной клик по типу техники в списке

**Способ 2:**
1. Выберите тип техники
2. Нажмите кнопку **"Открыть"**

Файл откроется в программе по умолчанию для данного типа файлов.

### Замена регламента

1. Выберите тип техники с существующим регламентом
2. Нажмите **"Добавить файл"**
3. Подтвердите замену старого файла новым

### Удаление регламента

1. Выберите тип техники
2. Нажмите кнопку **"Удалить"**
3. Подтвердите удаление

## Типичный сценарий использования

### Подготовка к техническому обслуживанию

1. Вы видите, что подходит срок ТО для Камаза
2. Открываете вкладку **"История ТО"**
3. Нажимаете **"Регламенты"**
4. Дважды кликаете на **"Камаз"**
5. Открывается файл с регламентом ТО
6. Вы смотрите, какой пробег соответствует текущему интервалу
7. Передаете информацию в сервис для выполнения работ

## Хранение файлов

Файлы регламентов хранятся в папке `regulations/` в директории программы:
- **Windows:** `C:\Program Files\ASK\regulations\`
- Файлы сохраняются локально и не синхронизируются с облаком
- Конфигурация хранится в файле `regulations_config.json`

## Индикация статуса

В окне регламентов каждый тип техники имеет цветовую индикацию:

- **Зеленый фон** (✓ Загружен) - регламент добавлен и доступен
- **Желтый фон** (Не загружен) - регламент отсутствует

## Советы

- Используйте PDF формат для регламентов - он универсален и хорошо отображается
- Называйте файлы понятно перед загрузкой: "Регламент_Камаз_2024.pdf"
- Регулярно обновляйте регламенты при получении новых версий от производителя
- Создайте резервные копии файлов регламентов

## Ограничения

- Максимум один файл на каждый тип техники
- Файлы хранятся локально и доступны только на текущем компьютере
- При переустановке программы регламенты нужно добавить заново

## Устранение проблем

**Файл не открывается:**
- Убедитесь, что на компьютере установлена программа для открытия данного типа файлов
- Для PDF установите Adobe Reader или другую программу просмотра PDF

**Регламент пропал после обновления:**
- Файлы регламентов сохраняются в папке программы
- При обновлении через установщик файлы должны сохраниться
- Сделайте резервную копию папки `regulations/` перед переустановкой
