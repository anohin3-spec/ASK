# Система смен для водителей

## Описание
Добавлена система смен для водителей техники. Теперь можно закреплять за одной единицей техники двух водителей, работающих посменно.

## Настройка смен
- **1-я половина месяца**: с 1 по 14-15 число (в зависимости от количества дней в месяце)
- **2-я половина месяца**: с 15-16 до конца месяца
- **Весь месяц**: водитель работает постоянно (без смены)

## Применение миграции

### Вариант 1: Через Supabase Dashboard (рекомендуется)

1. Откройте https://supabase.com/dashboard
2. Выберите ваш проект
3. Перейдите в **SQL Editor** (слева в меню)
4. Создайте новый запрос и вставьте:

```sql
ALTER TABLE equipment_drivers 
ADD COLUMN IF NOT EXISTS shift_half INTEGER CHECK (shift_half IN (1, 2) OR shift_half IS NULL);

CREATE INDEX IF NOT EXISTS idx_equipment_drivers_shift ON equipment_drivers(equipment_id, shift_half);

COMMENT ON COLUMN equipment_drivers.shift_half IS 'Половина месяца: 1 - первая половина (1-14/15 число), 2 - вторая половина (15/16-конец месяца), NULL - весь месяц';
```

5. Нажмите **Run** для выполнения

### Вариант 2: Из файла миграции

Выполните SQL код из файла `migration_add_equipment_drivers.sql` в Supabase SQL Editor.

## Использование

### 1. Открытие диалога управления водителями

- Выберите технику в списке
- Нажмите правой кнопкой мыши
- Выберите **"👥 Управление водителями"**

### 2. Добавление водителя со сменой

1. Выберите водителя из списка
2. Укажите смену:
   - **1-я половина** - водитель работает с 1 по 14-15 число
   - **2-я половина** - водитель работает с 15-16 до конца месяца
   - **Весь месяц** - водитель работает постоянно
3. Нажмите **"➕ Добавить"**

### 3. Отображение в таблице

В колонке **"Водители"** отображаются:
- Все закреплённые водители
- У текущего активного водителя добавлена пометка **(в смене)**

**Примеры:**
- `Иван Камаз (в смене), Александр Камаз` - сейчас работает Иван
- `Сергей FAW` - водитель один, работает весь месяц

### 4. Удаление водителя

1. В диалоге управления выберите водителя из списка
2. Нажмите **"🗑 Удалить выбранного"**
3. Подтвердите удаление

## Автоматическое определение смены

Система автоматически определяет текущую смену на основе:
- Текущего числа месяца
- Количества дней в месяце

**Февраль (28 дней):**
- 1-я смена: 1-14 число
- 2-я смена: 15-28 число

**Месяцы с 30 днями:**
- 1-я смена: 1-15 число
- 2-я смена: 16-30 число

**Месяцы с 31 днем:**
- 1-я смена: 1-15 число
- 2-я смена: 16-31 число

## Синхронизация

Все изменения автоматически синхронизируются через облако (Supabase):
- Добавление/удаление водителей
- Изменение смен
- Отображение текущего водителя

Изменения видны на всех компьютерах в реальном времени.

## Ограничения

- Нельзя назначить двух водителей на одну и ту же смену
- Если смена уже занята, система предложит выбрать другую
- Максимум 2 водителя со сменами + неограниченное количество водителей "на весь месяц"
