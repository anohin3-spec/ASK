# 🔧 Устранение проблемы "Не удалось добавить файл регламента"

## Быстрая диагностика

Когда вы открываете окно "Регламенты", программа автоматически проверяет систему и покажет предупреждение, если что-то не настроено.

## Причина 1: Таблица 'regulations' не создана ❌

### Симптомы:
- При открытии окна "Регламенты" появляется предупреждение
- При попытке добавить файл - ошибка

### Решение:
1. Откройте [Supabase Dashboard](https://supabase.com/dashboard)
2. Выберите ваш проект
3. Откройте **SQL Editor** (слева в меню)
4. Скопируйте весь текст из файла `migration_add_regulations.sql`
5. Вставьте в редактор
6. Нажмите **Run** или F5
7. Должно появиться сообщение "Success. No rows returned"
8. Перезапустите программу

### Проверка:
В SQL Editor выполните:
```sql
SELECT * FROM regulations;
```
Если таблица создана, вы увидите пустую таблицу (без ошибок).

---

## Причина 2: Bucket 'regulations' не создан ⚠️

### Симптомы:
- Предупреждение при открытии окна "Регламенты"
- Ошибка при загрузке файла

### Решение (автоматическое):
Bucket создается автоматически при первой попытке загрузки файла, ЕСЛИ:
- ✅ Таблица regulations создана
- ✅ У вас права администратора

### Решение (ручное):
1. Откройте Supabase Dashboard → **Storage**
2. Нажмите **New bucket**
3. Имя: `regulations`
4. Включите **Public bucket** ✅
5. Нажмите **Create bucket**

---

## Причина 3: Нет прав доступа 🔒

### Симптомы:
- Ошибка "permission denied" или "insufficient privileges"

### Решение:
1. Убедитесь, что вы вошли как **администратор** (admin или superadmin)
2. Обычные пользователи и менеджеры НЕ могут загружать регламенты

### Как проверить свою роль:
- Посмотрите на заголовок окна программы
- Должно быть указано: "Admin" или "SuperAdmin"

---

## Причина 4: Программа работает в локальном режиме 💾

### Симптомы:
- Предупреждение "Облачное хранилище недоступно"

### Решение:
1. Проверьте файл `.env` в папке программы
2. Убедитесь, что установлено:
   ```
   MODE=cloud
   ```
   (НЕ `MODE=local`)
3. Перезапустите программу

---

## Причина 5: RLS политики не настроены 🛡️

### Симптомы:
- Ошибка "new row violates row-level security policy"
- Или "permission denied for table regulations"

### Решение:
Выполните в SQL Editor:

```sql
-- Разрешить чтение всем
CREATE POLICY "Регламенты доступны всем пользователям" ON regulations
    FOR SELECT
    USING (auth.role() = 'authenticated');

-- Разрешить управление админам
CREATE POLICY "Только админы могут управлять регламентами" ON regulations
    FOR ALL
    USING (
        auth.jwt() ->> 'role' = 'admin' OR 
        auth.jwt() ->> 'role' = 'superadmin'
    );
```

Если политики уже существуют (ошибка "already exists"), они настроены правильно.

## Причина 6: Storage политики для bucket не настроены 📦

### Симптомы:
- Файл загружается, но запись в таблицу не создается
- Или наоборот - запись создается, но файл не загружается

### Решение:
Выполните в SQL Editor:

```sql
-- Чтение файлов
CREATE POLICY "Регламенты доступны для чтения всем"
ON storage.objects FOR SELECT
USING (
    bucket_id = 'regulations' AND 
    auth.role() = 'authenticated'
);

-- Загрузка файлов (админы)
CREATE POLICY "Админы могут загружать регламенты"
ON storage.objects FOR INSERT
WITH CHECK (
    bucket_id = 'regulations' AND 
    (auth.jwt() ->> 'role' = 'admin' OR auth.jwt() ->> 'role' = 'superadmin')
);

-- Удаление файлов (админы)
CREATE POLICY "Админы могут удалять регламенты"
ON storage.objects FOR DELETE
USING (
    bucket_id = 'regulations' AND 
    (auth.jwt() ->> 'role' = 'admin' OR auth.jwt() ->> 'role' = 'superadmin')
);
```

## Частые ошибки и их значение

| Ошибка | Причина | Решение |
|--------|---------|---------|
| `relation "regulations" does not exist` | Таблица не создана | Выполните миграцию SQL |
| `permission denied for table` | Нет прав или RLS не настроен | Проверьте роль пользователя и политики |
| `Bucket not found` | Bucket не создан | Создайте bucket вручную или он создастся автоматически |
| `invalid byte sequence` | Проблема с кодировкой имени файла | Используйте английские имена файлов |
| `file too large` | Файл превышает лимит | Максимум 50 MB, уменьшите размер PDF |
