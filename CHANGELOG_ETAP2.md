## 📁 Новые файлы

### 1. `auth_manager.py` (270 строк)
**Менеджер аутентификации** - управление входом, паролями и сессиями

**Основные методы:**
- `hash_password(password)` - хеширование пароля с bcrypt
- `verify_password(password, hash)` - проверка пароля
- `login(username, password)` - вход в систему
- `logout()` - выход из системы
- `change_password(old, new)` - смена пароля
- `has_permission(permission)` - проверка прав доступа
- `create_user(...)` - создание пользователя (только admin)

**Свойства:**
- `current_user` - данные текущего пользователя
- `current_company` - данные текущей компании

### 2. `login_dialog.py` (365 строк)
**Диалоги входа и смены пароля**

**LoginDialog:**
- Красивый интерфейс входа
- Валидация полей
- Подсказка с учетными данными по умолчанию
- Приветствие при успешном входе

**ChangePasswordDialog:**
- Смена пароля текущего пользователя
- Проверка текущего пароля
- Валидация длины нового пароля
- Подтверждение пароля

## 🔐 Безопасность

### Реализовано:
✅ Хеширование паролей с bcrypt (salt + hash)  
✅ Пароли никогда не хранятся в открытом виде  
✅ Проверка активности аккаунта (`is_active`)  
✅ Валидация минимальной длины пароля (6 символов)  
✅ Автоматическое шифрование при первом входе  
✅ Очистка сессии при выходе  

### Права доступа:
- **admin** - полный доступ (создание пользователей, все операции)
- **manager** - управление техникой, водителями, ТО
- **user** - просмотр и базовые операции

**Иерархия:** admin > manager > user

### Как протестировать:

2. Введите логин: `admin`
3. Введите пароль: `admin123`
4. Нажмите "Войти"
5. Проверьте меню "Файл" → "Сменить пароль"
6. Попробуйте сменить пароль
7. Выйдите из программы и войдите с новым паролем

### Проверка безопасности:
- ❌ Неверный логин → отклонен
- ❌ Неверный пароль → отклонен
- ❌ Пустой логин → предупреждение
- ❌ Пустой пароль → предупреждение
- ❌ Слишком короткий пароль (< 6) → отклонен при смене
- ❌ Несовпадение паролей → отклонено при смене

## 💡 Использование API

### Вход в систему
```python
from database import Database
from auth_manager import AuthManager

db = Database()
auth = AuthManager(db)

# Попытка входа
result = auth.login('admin', 'admin123')
if result:
    user = result['user']
    company = result['company']
    print(f"Вход выполнен: {user['full_name']}")
    print(f"Компания: {company['name']}")
```

### Проверка прав
```python
if auth.has_permission('admin'):
    print("Администратор - полный доступ")
elif auth.has_permission('manager'):
    print("Менеджер - управление данными")
else:
    print("Пользователь - базовый доступ")
```

### Смена пароля
```python
success = auth.change_password('admin123', 'newPassword456')
if success:
    print("Пароль изменен")
```
